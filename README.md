# PDF to Web Form

Convert PDF documents into interactive, fillable web forms with AI-assisted field detection and PyMuPDF stamping.

## 🚀 Quick Start (Single Command)

To run both the **Vite React Frontend** and the **FastAPI Python Backend** together in one terminal:

```bash
npm run dev
```

*(Or simply double-click `start.bat` on Windows)*

- **Frontend**: [http://localhost:5173](http://localhost:5173)
- **Backend API**: [http://127.0.0.1:8000](http://127.0.0.1:8000) (Interactive Swagger Docs: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs))

### Running Individually (Optional)

- **Frontend only**: `npm run dev:frontend`
- **Backend only**: `npm run dev:backend`
- **Build production bundle**: `npm run build`
